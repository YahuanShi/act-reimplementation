# ACT Reimplementation

A structured reimplementation and analysis of Action Chunking Transformer (ACT) for robot learning, focusing on imitation learning with chunked action prediction and transformer-based policy modeling.

## Objectives

### Mechanism Understanding
Analyze how action chunking reduces effective horizon and mitigates error accumulation in imitation learning, and how the transformer architecture models observation-to-action mappings.

### Pipeline Reproduction
Reproduce the end-to-end imitation learning pipeline, including data collection, sequence processing, and chunked action prediction.
